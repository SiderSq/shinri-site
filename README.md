# SHINRI TRIAL // NODE 04-271 ARCHIVE
### Интерактивный терминал расследования для отыгровки Нагито Комаэды на сервере Shinri Trial

Полноценная закрытая система цифрового архива, созданная специально для ARG-расследования и отыгровки **Нагито Комаэды** на сервере **Shinri Trial** (https://shinri-trial.ru).

---

## 🔒 Безопасность и защита от спойлеров

1. **Никаких кодов и подсказок на экране:**
   - Стартовый код доступа и ключ аварийного восстановления **не отображаются** на сайте. Организатор сам распределяет их по внешним ресурсам (Discord, Google Drive, игровые каналы).
   - В логе сбоя и окне восстановления удалены любые спойлерные приписки.
2. **Скрытая панель администратора:**
   - Кнопка «АДМИН» полностью убрана из шапки сайта. Обычные игроки не видят признаков панели управления.
   - Панель куратора открывается только по прямому скрытому адресу **`/admin`** (или `#admin`), либо по секретной комбинации клавиш **`Ctrl + Shift + A`**.
   - На экране авторизации админа удалены любые подсказки паролей.
3. **Удалена вкладка «Улики: X пуль правды»:**
   - Чтобы игроки не получали готовые ответы с указанием букв и их порядковых номеров, отдельная вкладка улик исключена.
   - Игроки исследуют **Документы**, **Сообщения**, **Журнал** и **Медиа**, самостоятельно находя нестыковки во времени и фактах.
4. **Защита от инспекции через DevTools / Сеть:**
   - Сервер отдаёт клиенту очищенные данные без раскрытия истинного имени убийцы, скрытых меток букв или внутренних подсказок.

## 🚀 Запуск и управление

```bash
# Запуск сервера
npm start
```
Сервер работает на **`http://localhost:3000`**.

### Быстрый доступ для куратора:
- Откройте `http://localhost:3000`
- Нажмите **`Ctrl + Shift + A`** (или откройте `http://localhost:3000/admin`)
- Введите пароль куратора (`shinri-admin-hope-2026`) для управления делом и мгновенного сброса блокировок IP.
