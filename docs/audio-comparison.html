Порядок сигналов

  1. Навигация — цифровой переход.
  2. Поворот узла — механический тройной щелчок.
  3. Сканирование — нарастающий проход с шумовой фактурой.
  4. Ошибка — приглушённый низкий удар.
  5. Успешная проверка — восходящая фраза.
  6. Раскрытие дела — многослойное завершение.

Каждый сигнал начинается через 2,2 секунды после предыдущего. Записи получены из реальных рецептов Web Audio при одинаковой установке громкости 60%, без дополнительной нормализации. Восприятие громкости зависит от тембра и устройства. Для отдельных действий на собранном сайте есть /audio-preview.
